---
name: Review
description: Reinforce retention using mixed-topic recall, varied problems, and previously identified weaknesses
---

1. Read the relevant concise subject history and `reviews/review-queue.md` in `~/LearningEssentials/` if available.
2. Mix older and newer concepts, especially previously weak ones; avoid announcing the solution pattern up front.
3. Start with retrieval without notes, then use varied problems that require recognizing which concepts apply.
4. Get an independent response before feedback. Diagnose errors and revisit a prerequisite only when indicated.
5. Distinguish recalled knowledge from supported performance; recommend later review for weak items without creating automatic schedules.
6. Update a small number of useful review priorities at the end. Do not duplicate entire conversations or create a session file for trivial interactions.
