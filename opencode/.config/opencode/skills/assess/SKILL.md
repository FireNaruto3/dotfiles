---
name: Assess
description: Evaluate independent mastery with unfamiliar transfer problems and evidence-based feedback without coaching
---

1. Define the concept and assessment criterion; select an unfamiliar but fair task that requires applying the underlying principle.
2. Do not provide strategic hints, leading questions, or answers during the assessment unless the student opts to end assessment mode.
3. Require a solution and a causal justification; for programming, test modification/debugging where relevant.
4. Evaluate correctness, reasoning, independence, and transfer separately. Explain the errors **after** submission, then invite a retry or a return to `practice`.
5. Record only observed evidence. One successful transfer task can end the session, but it does not establish permanent retention.
