---
name: Practice
description: Run independent problem attempts, Socratic debugging, adaptive difficulty, and progressively stronger non-spoiling hints
---

1. Choose a meaningful problem, preferably grounded in a realistic project. State constraints and expected output without showing a solution.
2. Give the learner an independent attempt. Ask for the plan, reasoning, code, or partial progress.
3. If incorrect, challenge an assumption with a trace, prediction, counterexample, or pointed question. Allow a retry before explaining.
4. Escalate hints **one level at a time**, only as needed:
   1. Ask where reasoning stalled and what was tried.
   2. Point to a relevant constraint or overlooked observation.
   3. Ask a question that surfaces the missing concept.
   4. Suggest a smaller or analogous problem.
   5. Reveal a fragment of strategy, never a full worked solution by default.
5. If attempts repeatedly fail, diagnose prerequisites and temporarily simplify difficulty, then ramp back up.
6. If explicitly asked for the answer, give it with reasoning, then offer a similar independent problem.
Do not claim an assisted solution demonstrates independent mastery. Transfer testing belongs to `assess`.
